# Design

Create work that is specific to the subject, audience, medium, and intended action. Treat the request as a design brief: preserve stated brand, platform, content, and accessibility constraints; infer only the details needed to make a coherent proposal.

## Establish a direction before making

Choose a single, defensible visual idea rather than assembling familiar style signals. Define a compact system for:

- palette: 4–6 purposeful colors with contrast-aware roles;
- typography: one or two clearly differentiated families and a readable scale;
- composition: hierarchy, alignment, density, and the element that should be remembered;
- material: imagery, illustration, texture, or geometry only when it contributes to the idea.

If alternatives would materially change the result, present concise options or state the assumption used. Use an existing product's visual language when extending it; do not replace it merely to make the work more expressive.

## Design the information, not decoration

Let structure communicate meaning. Use labels, borders, dividers, numbering, and motion only when they clarify hierarchy, sequence, state, or interaction. Avoid generic patterns unless the brief specifically calls for them: arbitrary gradient washes, uniform rounded-card grids, decorative all-caps eyebrows, isolated accent words in headlines, and repeated reveal animations.

Typography is part of the composition. Keep body copy comfortably readable (usually under 80 characters per line), use deliberate spacing and weight, and avoid treating text as filler. Write clear, user-centered labels and action names; error and empty states should say what happened and what a person can do next.

For static visual work, favor form, space, color, and image over explanatory text. Use a limited, intentional palette and ensure every element has adequate margins and does not collide with other content or canvas edges.

## Build with restraint

Spend visual boldness on one memorable gesture, then make the surrounding system quiet and disciplined. Make contrast, focus treatment, keyboard interaction, responsive behavior, and reduced-motion support part of the design—not a final cosmetic pass. Use motion principally to explain a response to an action; a single composed ambient moment can be appropriate when it serves the concept.

For original art or illustration, develop an original visual language from the request. Do not imitate a living artist or reproduce a copyrighted work's distinctive composition.

## Review the output

Before delivering, inspect the rendered result when the environment permits. Check that it serves the stated task, works at the intended size and on narrow viewports where relevant, maintains legible contrast, avoids overflow and accidental overlap, and still feels particular to this brief after removing any nonessential embellishment.
